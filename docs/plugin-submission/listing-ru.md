# КС РФ: помощь заявителю

Документы и проект обращения

Для самостоятельных заявителей и юристов. Помогает разобрать документы, объяснить возможный конституционный вопрос, проверить основания и возражения, подготовить рабочий проект и список дальнейших действий. Включает полный набор навыков КС РФ и переносимую среду выполнения. Распознавание сканов (OCR) и создание DOCX/PDF доступны, если используемая среда предоставляет необходимые инструменты. Проект требует юридической проверки человеком. Подпись, платёж, подача и юридическое одобрение остаются за человеком.

## Запросы для начала

1. Хочу обратиться в Конституционный Суд. Помоги разобраться, с чего начать.
2. Разбери мои документы и объясни возможные пути защиты.
3. Проверь проект моей жалобы и предложи исправления.
