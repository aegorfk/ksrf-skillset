# Release notes for review

## Русский

Первая заявка ksrf-applicant в общий каталог. Пакет объединяет 16 навыков и сопроводительные материалы для людей, самостоятельно готовящих обращение в Конституционный Суд РФ: разбор документов, исследование правовой проблемы, подготовку и проверку рабочего проекта.

Поставка Skills only не объявляет удалённый MCP-сервер, OAuth или собственное облачное хранилище. Исполняемый код и отдельная локальная среда включены, но выполнение зависит от инструментов хоста. Локальная установка, проверка целостности и синтетический документный маршрут проверялись отдельно; это не независимая оценка юридического качества и не подтверждение установки в любом аккаунте ChatGPT.

Для базовой проверки не нужны ключи автора или тестовый аккаунт внешнего сервиса. Используйте предоставленные синтетические сценарии и документы без персональных данных. Подписание, платёж, подача и юридическое одобрение остаются действиями человека. Конкретная версия заявки определяется финальным манифестом выпуска.

## English

Initial ksrf-applicant submission to the public directory. The package brings together 16 skills and supporting materials for people preparing a complaint to the Constitutional Court of the Russian Federation: document review, research, drafting, and review of a working complaint.

This Skills only package declares no remote MCP server, OAuth, or publisher-operated cloud storage. Executable code and an optional isolated local environment are included; actual execution depends on host tools. Local installation, integrity checks, and synthetic document workflows were tested separately. These tests do not establish independent legal quality or installation support in every ChatGPT account.

Basic review requires no author credentials or external-service test account. Use synthetic scenarios and documents without personal information. Signing, payment, filing, and legal approval remain human actions. The submitted version must match the final release manifest.
