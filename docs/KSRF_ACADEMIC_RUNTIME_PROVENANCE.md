# Source-only provenance академических дельт KSRF runtime

`status: source_only`

`runtime_dependency: false`

Этот документ хранит историю разработки, библиографическую атрибуцию и локаторы академических, сравнительных и состязательных материалов, из которых извлекались проверочные операции. Он не входит в пользовательский runtime skills и не нужен для выполнения ни одной карты, adverse-проверки или stop rule. Установленные skills должны работать без исходных книг, статей, жалоб, локального архива, контрольных сумм и доступа к библиографическим ссылкам.

Ни один материал ниже не подтверждает действующее российское право, применение нормы в деле, позицию Конституционного Суда РФ, допустимость жалобы или доступный remedy. Официальные российские нормы, акты, их версии, URL и контрольные суммы намеренно остаются в runtime reference-файлах: они функционально нужны для authority/currentness gates и не относятся к вынесенной отсюда книжной provenance.

Текст блоков сохранён вместе с исходной атрибуцией, пагинацией, оговорками и SHA. Заголовок каждого блока указывает runtime-файл, из которого provenance была вынесена; сами операции в этом файле остались самодостаточными и source-neutral.
