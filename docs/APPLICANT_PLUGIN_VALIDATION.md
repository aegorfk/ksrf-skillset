# Проверка плагина 1.0.0

Дата проверки: 2026-09-12. Область: переносимость программного пакета и
синтетический путь подготовки документов. Юридическое качество работы модели
с реальным делом этой проверкой не устанавливается.

## Исходники и установка

- Полная строгая проверка source-профиля: 16/16 навыков, 0 ошибок,
  0 предупреждений; runtime self-containment, eval schemas и public-source
  safety проверены штатным валидатором.
- Чистая установка штатным `install.sh --target` и последующий `--verify`:
  16/16 навыков, 296 файлов, 10 895 109 байт, 0 ошибок и предупреждений.
- SHA-256 дерева runtime:
  `0a098d45c194227f918143c24a50b9d3adbba942df5dfc13862c248f3e3572c3`.
- Манифест плагина принят валидатором plugin-creator. Локальная проверка
  дистрибуции подтверждает 310 перечисленных файлов плюс сам манифест.
- Сборка проверяет полное замыкание 16 навыков, детерминированность ZIP,
  изменение исходников во время сборки, ссылки, запрет приватных исходников,
  буквальных секретов, символических ссылок и опасных путей. Неучтённые файлы,
  включая исполняемый Python bytecode, отклоняются проверкой целостности.

## Исполняемая среда

На macOS подготовлено новое изолированное окружение с 11 точными версиями
Python-зависимостей. Импорты и `pip check` прошли. Реально выполнены начало
разбора, создание папки дела, intake, извлечение DOCX, рабочий экспорт DOCX/PDF,
повторная проверка хешей. Строгий выпуск без полномочий человека отклонён.
Диагностика корректно показывает отсутствие локального `pdftotext`; успешный
экспорт не подменяет проверку этой отдельной операции.

Контейнерная среда проверяется на Linux ARM64. Синтетический smoke включает
11 проверок: первоначальный разбор, операции с папкой дела, извлечение DOCX,
двухстраничный рабочий DOCX/PDF, Poppler, настоящий OCR изображения,
целостность результата и отказ строгого выпуска без одобрения. Страницы
просмотрены в исходном разрешении: наложений и обрезанного текста не выявлено.
Техническое наличие PDF само по себе визуальную проверку не заменяет.

Образ собирается из точного сгенерированного desktop payload. Финальный
идентификатор образа и результат запуска с `--network none --read-only`,
непривилегированным UID и временным профилем LibreOffice записываются во
внешнюю квитанцию выпуска; это позволяет связать их с уже опубликованным
commit без самореферентного изменения исходников.

## Отдельные состояния выпуска

`plugin/use-cases.json` содержит 20 ожидаемых сценариев, покрывающих все
16 навыков. Это каталог для будущей проверки поведения, а не результаты
исполнения моделью, пользовательского исследования или независимого legal eval.

Проверка live SHA канонического репозитория, сборка с `--require-clean`,
публичная дистрибуция и повторное скачивание ZIP выполняются после публикации
исходников. Их фактические commit, SHA-256 и результаты записываются в
GitHub Release и локальную квитанцию выпуска по
[протоколу](APPLICANT_PLUGIN_RELEASE.md).

Импорт полного пакета в авторизованный аккаунт ChatGPT не проверен.
Размещённый HTTPS runtime отсутствует. Приём в общий каталог OpenAI не
запрашивался. Пакет для браузера предоставляет методологию и исполняемые
ресурсы, доступ к которым зависит от инструментов конкретного аккаунта.
