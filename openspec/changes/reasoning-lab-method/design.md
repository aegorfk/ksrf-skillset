# Design

Reference открывается только при вопросах, контрастах, сравнении формулировок
или анализе изменения аргумента. Не вводит обязательные семь разделов в
любой ответ. Не копирует проектный сборщик и не требует доступа к корпусу.
Минимальный переносимый набор: основной автономный guide, новый reference,
встроенные универсальные операции; данные нового дела подаёт пользователь.

Проверки: самостоятельная холодная синтетическая проба с изменением условия,
source/runtime validators, полный root test suite, manifest и clean-room
установка. Публикация: один атомарный commit от live main, свежая SHA-сверка,
штатная глобальная установка только после публикации.
