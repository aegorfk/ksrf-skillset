# Автономная проверка рассуждения

## Why
Пользователь поручил семь направлений содержательного использования корпуса,
начиная с цепочки, наблюдаемости и контрастов. В runtime переносится только
универсальная методика, а не исходы или зависимость от проектного EVAL.

## What Changes
Условный маршрут из argument-patterns к автономному reference: причинный
переход, знание и доступность версии, контрасты, адресные вопросы, сравнение
формулировок, траектория и содержательная критика. Существующие 22 операции
и скрипты сохраняются. Новая методика dated evaluator-derived.

## Impact
Один runtime reference и один короткий router. Нет исходных дел, URL поиска
исхода, закрытой типологии, автоматического legal/training promotion.
