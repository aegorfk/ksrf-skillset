## Проверка выпуска после commit

Публикация не подтверждается этим предпубликационным снимком. После создания
commit обязательны push в main, свежая проверка `HEAD == live main`, штатный
publication guard и чтение установленных файлов после доставки. Свидетельство
этого этапа — фактический SHA выпуска и результат postflight в отчёте задачи;
дополнительный commit ради записи собственного SHA не создаётся.
