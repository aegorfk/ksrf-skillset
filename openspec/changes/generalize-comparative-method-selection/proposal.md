# Universal comparative method selection

The user requires KSRF complaint skills to work from any dispute and subject matter. Existing autonomous methods are already general, but comparative entrypoints, the default public example and transfer checks overemphasize wage indexation. This can bias problem discovery and selection of foreign acts.

Make the existing universal argument workflow the shared starting point. Select comparative methods by the rule, harm mechanism, necessary premise and requested protection. Retain verified source cases, exact quotations and optional topical examples. Do not create another closed method catalog or presume every case presents a constitutional defect.

Acceptance: unrelated subjects can be analyzed without invented wage facts, methods require their actual premises, counterexamples can change the conclusion, and an ordinary application error can remain an ordinary error. Source provenance and filing safeguards remain valid. Publish one scoped release to canonical main and install the verified package.
