## Why

Пользователь одобрил проверку эффекта пяти гипотез на одном и том же реальном досье до/после со скрытой версией методики для независимого юриста. Внедрение инструкции, source audit и тесты не отвечают на этот вопрос.

## What Changes

- Зафиксировать последовательный парный эксперимент H1 → H2 → H3 → H4 → H5.
- Различить incremental effect Hn относительно Hn-1 и итоговый эффект H5 относительно исходного baseline.
- Не использовать старый diagnostic-only набор как автоматически разрешённый substantive corpus.
- Зафиксировать отрицательные и неопределённые результаты, ошибки обоих типов, стоимость и отсутствие юридического одобрения.
- Оставить change открытым до реальных outputs, trace receipts и независимых человеческих оценок.

## Capabilities

### New Capabilities

- `ksrf-five-method-comparison`: неизменный реальный input и независимая слепая оценка пар.

### Modified Capabilities

Нет: существующий eval runtime не изменяется.

## Impact

Локальный private evaluation workspace, существующие Langfuse/DeepEval entry points, reviewer handoff. Запуск и качество ещё не подтверждены. В публичный skillset не попадают inputs/outputs дел, ключ разослепления или персональные данные.
