# Design

Существующий `check_argument.py` остаётся необязательным. Старые входы
принимаются; новые поля включают более точную проверку, но их отсутствие
не доказывает отсутствие редакционных вставок или самостоятельных оснований.

`excluded_spans` документа содержит start/end/quote/reason. Точное пересечение
цитаты с исключённым диапазоном блокирует её использование в аргументе.
Исключённый фрагмент остаётся в исходном тексте для аудита; программа не
обнаруживает его автоматически и не гарантирует очистку памяти модели.

`completeness` = complete/partial/unknown описывает предоставленный текст,
не происхождение версии. partial и unknown сохраняют evidence gap.

`branches` связывают demand_id, outcome_id и ground_ids через claims.slot;
каждый ground явно перечисляет for_demand_ids. Это проверка заявленных связей,
не юридической достаточности основания. Отсутствие branches не повышает полноту.

Хеш всего JSON-входа меняется при любой правке текста/связей/возражений.
Это identity контекста, не электронная подпись и не expert approval.
Уточнения выпущены 2026-09-06; as-of до даты checker release блокируется.
