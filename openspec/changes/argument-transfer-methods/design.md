# Design

Method library JSON является единым источником условий для CLI и агента.
Markdown объясняет применение. Вход — доказанные посылки с SHA и locator;
выход — candidate/needs_evidence/not_applicable/blocked, без рейтинга готовности.
Проверки источника для конкретной жалобы остаются за исследователем: наличие
SHA и locator технически не доказывает правду посылки.

Релиз выведен из evaluator-only источников и имеет дату 2026-09-05. Статус
historical_eval_allowed=false распространяется на все карточки. Удаление
номеров решений не стирает lineage. Новый скилл не подключается к frozen EVAL.
Текущий полный skillset тоже нельзя считать as-of snapshot по дате одной ссылки.
