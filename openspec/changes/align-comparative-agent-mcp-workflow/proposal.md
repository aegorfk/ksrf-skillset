# Агентное сравнительное исследование через MCP

## Why
Целевой сценарий — подготовка жалобы в КС РФ по любому предмету: агент использует доступную базу зарубежных судов через MCP, читает полные акты и закрывает пробелы прямым официальным поиском. Транспорт, поисковая выдача и юридическая проверка выполняют разные функции. Единичный запрос и частичный векторный индекс не доказывают отсутствия практики.

## What Changes
- Общий переносимый маршрут исследования в constitutional-comparative-research.
- Ссылки на маршрут из исследования аргументов и цикла подготовки жалобы.
- Актуальное обнаружение возможностей, разделение foreign/HUDOC/российских источников, контроль пагинации и обезличивание внешних запросов.
- Проверка самостоятельной работы без MCP, обработки неполного охвата и контраргументов.
- Сверка контрольных digest/диапазонов существующих тестов: изменённый entrypoint и ранее опубликованные синтетические evals; исходные evals не меняются.

## Impact
Только методика использования доступных инструментов. Не меняются юридические основания, правила допустимости, модельный индекс, коннекторы, облачная инфраструктура или автоматические approvals. Новых правовых приёмов из актов в этот выпуск не извлекается.
