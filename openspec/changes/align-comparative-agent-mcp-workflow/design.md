# Design

Единый reference agent-research-workflow.md хранит последовательность принятия решений: российский вопрос → доступные capabilities и границы корпуса → адаптивные лексические/точные/смысловые запросы → полный контекст поддерживающих и неблагоприятных актов → адресный официальный поиск → ограниченный сравнительный результат.

MCP предпочтителен как доступный структурированный вход в библиотеку. CLI/API разрешены как равноценный путь к той же проверяемой реализации, а предоставленные официальные тексты позволяют работать без подключения. Методика не содержит фиксированных hostname, локальных путей, моделей, размеров top-k, счётчиков или перечня якобы всегда доступных инструментов. Расписание загрузки не является доказательством актуальности.

Сохраняются отдельные национальные/Russian/HUDOC маршруты и роли источников, точные цитаты и связи с версией. В публичный поисковый сервис передаётся обезличенный правовой вопрос; raw case packages остаются в своём privacy-контуре. Результат переносится в существующий ledger без нового обязательного JSON или дополнительного filing gate.

Три entrypoint связываются с одним reference; существующий corpus-and-provenance.md уточняет обнаружение capabilities и пагинацию. Проверка — независимый проход на синтетических входах, строгий source/runtime validator, offline self-containment, существующие тесты, clean-room install и проверка опубликованного состава.
