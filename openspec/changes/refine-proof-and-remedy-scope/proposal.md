# Различение доказательного вывода и объёма меры

## Why
Переносимые приёмы должны различать недоказанность, доказанное отрицание и
существование правоприменительного акта. Сохранение одного основания после
устранения другого не удостоверяет сохранение прежнего объёма санкции.

## What Changes
- Самодостаточная методика с условными ± примерами без исходного корпуса.
- Необязательные структурированные проверки операторов и остаточного эффекта
  в portable checker; старые пакеты совместимы, отсутствие проверки видно.
- Синтетические тесты и проверка работы установленного скилла без корпуса.

## Impact
Только prospective agent-candidate workflow. Ни historical EVAL, ни semantic
truth, ни юридическое одобрение из структурной проверки не возникают.
