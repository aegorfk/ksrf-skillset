# Why

A real complaint infers a substantive interpretation from a remand and from the
court not choosing a different disposition. Existing guidance tracks changed
reasons but does not operationalize the distinction between an express holding,
a failure to give reasons, an issue left open, and the subsequent court's own rule.
This can overstate the authority supporting a complaint's constitutional issue.

# What Changes

- Extend the existing cross-instance drafting method with a bounded remand review.
- Link the social-entitlement method to that review without duplicating it.
- Ground the revision in available real sources; preserve gaps in the remaining
  judicial chain and do not present retrospective review as a blind experiment.
- Publish and install the exact reviewed release through the existing guarded path.

# Impact

Two methodology references, a short user-facing description, the release manifest,
and this OpenSpec change. No new machine status, gate, schema, evaluator, synthetic
case, native epoch, external authority, or filing action. Original complaints and
reconstructive derivatives remain outside public Git.
