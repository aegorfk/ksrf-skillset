# Why

Newly supplied complaint and expert opinions expose three reusable gaps: transferring confidentiality guarantees between investigative procedures, locating an individual's protected interest independently of an organisation, and distinguishing official publication from mere access to a text. Historical arguments must be compared with each document's own constitutional outcome rather than copied into today's complaint.

# What Changes

- Add two self-contained, two-pass methodological cards and route them from the complaint, argument, doctrine, QA and execution skills.
- Add synthetic source-only scenarios and regression checks without originals or reconstructive derivatives.
- Credit verified authors and donors with public professional and final-act links; retain explicit gaps instead of invented complaint links or authorship.
- Publish the scoped release and install canonical globals only after fresh remote verification.

# Capabilities

## New Capabilities

- `ksrf-confidentiality-and-expert-opinions`: source-bound transfer of safeguards, standing and publication analysis.

# Impact

Global KSRF methodology and its public source repository; no parser, network retrieval runtime, legal approval or filing behaviour changes. The large newly collected Sutyajnik/SPbGU archive is a separate queue unless the user expands this review; this release covers the three standalone supplied documents.
