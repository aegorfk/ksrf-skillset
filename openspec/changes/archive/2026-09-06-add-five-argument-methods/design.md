## Context

Baseline: `55783143c77e5a9cdc3f70c4321fd20f1b2adde4`. Установленные ветви рассуждения уже содержат competing interpretations, strongest objection, маржинальный баланс, universalization и competence gate. Их не дублируем и не заменяем.

## Goals / Non-Goals

Goal: при применимом триггере получить точную предлагаемую правку, её основание, сохранённое возражение и ограничение вывода.
Non-goals: новый обязательный тест КС РФ, автоматическая правовая квалификация, скрытый выбор портфеля, запуск RSI/heartbeat, публикация материалов дела или заявление о росте качества.

## Decisions

Один компактный reference с пятью разделами, подключённый из builder и QA. Существующие справочники остаются владельцами полных тестов. Новый reference хранит только операционную дельту:

| Порядок | Уже есть | Добавляемое действие |
| --- | --- | --- |
| H1 | Перечень сильных толкований | Выделить минимальное расхождение посылок; проверить изменение результата при подтверждении и опровержении различителя |
| H2 | Adverse ledger | Сначала принять точную неблагоприятную позицию для анализа; вывести остаток требования; проверить материальность различения |
| H3 | Цель, пригодность, альтернативы | Сохранить цель и несомненные элементы; проверить дополнительный вклад именно спорного элемента и его защиту оппонентом |
| H4 | Universalization | Зафиксировать общее правило до отбора реальных пограничных дел; проверять условия включения/исключения и пересматривать правило на всех уже проверенных делах |
| H5 | Remedy/competence matrix | Отделить необходимую гарантию от механизма; проверить его заменимость и отбраковать узкое, но неэффективное средство |

Порядок реализации сохраняется отдельными этапами. Пропуск неприменимого приёма в конкретном деле объясняется; отсутствие сравнимого дела или источника оставляет локальную неопределённость. Составление рабочего проекта возможно; filing-ready вывод без зависимого доказательства невозможен.

Изученные прежде реальные материалы — development/source audit, не held-out. Технические regression tests проверяют доставку и границы инструкции, не силу аргумента. Текст до/после для эксперимента не реконструируется задним числом из уже увиденного результата.

## Risks / Trade-offs

Пять проверок могут раздуть текст. В жалобу переносится только решающий довод; рабочие таблицы остаются в memo. Для H4 незаполненная граница честнее вымышленного дела; для H3 отсутствие эмпирики не превращается в автоматическую победу заявителя. Для H5 минимальность не означает слабейшее средство.

## Validation

Проверка по реальным исходным документам с раздельными ролями сторон и суда; независимое агентское review инструкции; структурные тесты, strict validator, offline verification, full unit suite, clean-room install и OpenSpec. Содержательное сравнение человеком остаётся в отдельной открытой спеке; его отсутствие не скрывать в release report.
