# Why

The installed CLI requires release authority before rendering a document for legal review. This prevents useful work despite the router permitting provisional drafts. Existing evaluation emphasizes false admission and does not separately measure avoidable rejection of a researchable issue.

# What Changes

- Add a local working-draft route with visible uncertainty and no filing authority.
- Preserve the existing authenticated release route and its evidence requirements.
- Report evidence/authority, input, renderer and QA failures separately.
- Add a bounded, outcome-blind evaluation contract for false rejection, useful repair actions and draft completion.
- Provide a reproducible local dossier-to-review-package workflow and verify it against real rendering tools.
- Update skills to apply blockers to the dependent stage and claim; postpone optional infrastructure until the local route is demonstrated.

# Capabilities

## New Capabilities
- `ksrf-working-draft`: provisional local documents and review bundle.
- `ksrf-practical-evaluation`: separate admission, research and operational evaluation.

# Impact

Global complaint-cycle runtime and references, triage/explore/QA skills, source-only tests and evaluation helpers. No court submission, signature, payment, legal approval, new database, new LLM provider or disclosure of private case materials.
