# Design

## Source separation
Жалоба Сухова связывается с № 29-П/2019 по заявителю, предмету, описанной истории и требованию, а не по имени файла. Amicus ИППП от 28.03.2016 связывается с вопросом исполнения постановления ЕСПЧ по делу «Анчугов и Гладков» и № 12-П/2016. Публичный PDF amicus проверяется на совпадение с предоставленным файлом. Профессиональная главная страница Сухова не обозначается ссылкой на текст жалобы.

## Runtime method
Карточка статусных ограничений принадлежит `ksrf-rights-argument-builder`; карточка amicus — `ksrf-doctrine-research`. Они доступны из владельцев и общего цикла. Методы требуют доказательств нового дела, проверки действующей редакции и отдельного контроля последствий. Отсутствие запрета или санкции не объявляется свободой деятельности автоматически; молчание источника не доказывает отсутствие мотивов законодателя. Тезис автора, мнение отдельного судьи и мотивировка большинства не смешиваются.

## Validation
Регрессии проверяют достижимость карточек, границы источников, работоспособность без исторических файлов и ссылки атрибуции. Синтетические задания содержат все необходимые входы и явные ожидания, а не скрытую зависимость от частного корпуса. Они не являются результатами model/judge эксперимента. Не меняются замороженные наборы и критерии процессуальной готовности.

Две проверки точных снимков унаследовали устаревшие ожидания от базового commit `d2ad66ee0eb99d8f6ca1a769ca3859cc7134f413`: в `ksrf-case-triage` и `ksrf-argument-patterns` ранее добавлены маршруты к `norm-meaning-continuity.md`. Падения воспроизведены на неизменённой базе. По согласованию с пользователем обновляются только ожидаемые размеры и SHA-256 после проверки этих изменений; проверки не отключаются, сами два скилла в этом change не меняются.

## Release and local originals
Работа ведётся в чистом временном checkout актуального canonical main. После валидации создаётся один atomic release с обновлённым manifest; push проверяется свежим remote SHA. Глобальные skills синхронизируются только из чистого опубликованного checkout с проверкой отсутствия постороннего локального изменения. После извлечения методологии оригиналы переносятся без перезаписи: жалоба в частный архив жалоб, amicus в научные материалы. Локальный отчёт сохраняет hashes, источники, фактическую полноту чтения и ограничения доступа.
