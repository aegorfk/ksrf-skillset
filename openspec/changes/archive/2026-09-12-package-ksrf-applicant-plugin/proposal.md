## Why
Заявитель без юридической подготовки не может перенести текущие skills вместе с исполняемой средой одним понятным способом. Нужен распространяемый пакет с полным рабочим маршрутом, проверенными зависимостями и отдельными возможностями ChatGPT web и Codex desktop.

## What Changes
- Упаковать все 16 опубликованных навыков, включая компаративистику, их runtime, схемы и методические материалы по существующему allowlist.
- Добавить понятный вход для заявителя в основной skill: обычная история, документы, номер дела, проект, письмо Секретариата или акт КС РФ; технические действия выполняет агент.
- Добавить переносимую подготовку среды, проверку по конкретным операциям, запуск существующих CLI и воспроизводимую контейнерную среду.
- Выпускать браузерный пакет без desktop-only MCP-деклараций и настольный пакет с локальным runtime; описать реальные возможности и ограничения исполнения.
- Добавить сборщик, манифест происхождения, каталоги установки, инструкции, сценарии проверки и публичное распространение собранных файлов.
- Сохранить все существующие функции, источники, проверки и человеческие полномочия. Не включать частные дела, корпуса, ключи и настройки автора.

## Capabilities
### New Capabilities
- `ksrf-applicant-plugin`: полный пользовательский маршрут и переносимая дистрибуция для заявителей.
### Modified Capabilities
Нет изменения существующих юридических критериев или полномочий release.

## Impact
Глобальные KSRF skills через canonical publish-worktree, новые plugin build/runtime adapters, source-only tests, public documentation and generated distribution. Existing canonical installer contract is reused. External account provisioning, paid service access, universal directory approval and hosted deployment remain distinct from a tested software package.
