# Unified complaint document formatting

## Why
The user selected one consistent typographic standard for the complaint and prepared annex documents. The renderer previously mixed direct formatting with inherited template effects.

## What Changes
Apply reusable paragraph styles for the selected page geometry, typeface, spacing, heading hierarchy, numbered items, sources and footer. Preserve legal prose, evidence states, fields and links; only nonbreaking spaces after the number sign and literal-list tab spacing are display normalization. Add the annex naming rule for actual copies.

## Impact
The change affects document presentation and drafting instructions. It does not alter source records, evidence approval, filing readiness or release authority.
