# Design

Владелец — `ksrf-argument-patterns/references/hearing-derived-argument-patterns.md`,
раздел 6. Сохранить узнаваемую тему и обновить оглавление без дублирования workbook.

Условное рассуждение ограничено конкретной целью из материала с известной ролью.
Оно не подтверждает цель, её легитимность, факты заявителя или злоупотребление;
не закрывает основной довод против цели. Средство оценивается отдельно по уже
существующей методике. Для альтернатив сохраняется одна и та же цель внутри
условной ветви; её нельзя выдавать за установленную действительную цель.

Сохранить разграничение: условный ответ на оправдание не является завершённым
балансовым анализом. Неизвестная цель остаётся неизвестной в карточке цели и QA.
Не импортировать иностранный тест или новое распределение бремени.

Исходный кандидат о неблагоприятном индивидуальном факте не переносится: найденный
реальный источник относится к возможной цели ограничения, а не признанию факта.
Исход жалобы известен; проверка источника и редакторский review не являются blind eval.

Первый полный прогон выявил один ожидаемый exact-byte snapshot failure:
закреплён старый SHA reference. Старое значение независимо совпало с файлом live
base; новое — с точными байтами, прошедшими independent editorial review.
Обновить только этот literal в `test_hearing_guides_no_scalar_readiness.py`.
Не менять assertions, остальные hashes, критерии или ожидания правового результата.

Релиз — один атомарный commit от свежего live main, source/runtime QA, публикация,
проверка live SHA и только затем guarded установка глобальных skills.
