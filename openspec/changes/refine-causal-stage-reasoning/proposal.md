# Уточнить причинную цепочку и границы стадии

## Why

Самодостаточная методика должна различать последний барьер и предшествующую
квалификацию, которая определила его применение. Сравнение режимов по одному
выгодному условию теряет встречные гарантии; сравнение формулировок без проверки
доступной стадии ошибочно превращает пробел наблюдения в ошибку предсказания.

## What Changes

- Уточнить автономный reasoning workflow и U01 без переноса исходных дел.
- Добавить вымышленные положительные и отрицательные примеры.
- Сохранить evaluator-derived происхождение; никаких новых historical допусков.

## Impact

Только методика и packaging QA. Новые веса, индекс, корпус или юридический
автоматический классификатор не создаются. Выпуск всех 15 скиллов проверяется
по каноническому release contract.
