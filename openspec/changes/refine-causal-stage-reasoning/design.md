# Design

1. Развернуть причинную цепочку назад от исхода: факт → квалифицирующий критерий
   → выбранный режим → конечный барьер. Не объявлять любой upstream факт
   нормативным дефектом и не подставлять позднее обоснование в ранний источник.
2. Сравнить целые релевантные режимы и их функции; не собирать третий режим из
   выгодных частей. Встречное преимущество — контрдовод, не автоматическое
   оправдание любого ограничения и не арифметическая взаимозаменяемость прав.
3. Сохранить момент наблюдения. Отмена, новый мотив и временное регулирование
   из последующего решения доступны только отдельной ретроспективной оценке.
4. Развести чужую пару, недостающую стадию, ненаблюдаемую посылку и ошибку
   рассуждения. Проверка пары по двум сторонам выполняется вне blind контекста.
5. Примеры полностью вымышлены, не являются правовыми источниками. Тесты
   проверяют доставку методики без корпуса, а не юридическую истинность.
