# Source-bound comparative review

## Why
The current skill gives sound comparative guidance, but the running extractor only retains lexical navigation candidates. A repeatable substantive review must distinguish court reasoning from quoted positions and connect a proposed method change to an observed analytical improvement.

## What changes
- Add a progressively disclosed procedure for full-context, evidence-bound judicial analysis and issue/mechanism search.
- Classify proposed updates as new operation, refinement, counterexample, illustration or no change against the existing open method catalog.
- Add cross-subject forward inputs and separate review criteria for attribution, adoption, causal premises and unjustified transfer.
- Audit current Russian evaluation material availability and exposure outside the public repository; report actual admission gaps.

The pinned lexical extractor, existing source cards and legal filing authority remain unchanged. Backend packet preparation/acceptance belongs to the separate foreign-courts argument workbench.
