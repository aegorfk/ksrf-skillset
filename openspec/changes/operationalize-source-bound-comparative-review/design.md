# Design

Keep the comparative entrypoint concise. A new reference describes the operational review; existing provenance and comparison references retain ownership of source rules and comparative dimensions. No second method taxonomy or backend validator is introduced.

The agent reads a complete source packet or equivalent full act, identifies source evidence and separately labels its analytical inferences. Nodes and relations can represent premise, argument, objection, response, conclusion and consequence. Every asserted source relation requires contextual evidence; exact substring matching alone establishes neither author, adoption nor legal entailment. Unknown and rejected readings remain reportable results. Source/version changes invalidate the earlier analysis binding.

For skill updates, explain the observed mistake corrected and compare with existing operations before adding a rule. Negative and markerless acts are reviewed deliberately; related matters and source versions do not increase independent evaluation denominators. Russian transfer separates normative issue, application and injury, domestic authority, adverse interpretation and narrow remedy.

Source-only fixtures separate user inputs from evaluator criteria. Mechanical tests verify source bindings and separation; independent forward review verifies behavior. Existing real-act provenance tests and the pinned extractor hash remain regression checks. Russian material inventory stays local; prior published or studied target judgments are not blind inputs. Canonical publication occurs only after concrete root review and forward validation, through the existing clean publication protocol.
