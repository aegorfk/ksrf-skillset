# Где и как работает пакет

Оба варианта `ksrf-applicant` содержат полный набор из 16 навыков и соответствующих ресурсов. Разница среды определяет, какие программы она может запустить и где сохранятся результаты. Ни один вариант не переносит аккаунты автора, частные данные или юридические одобрения.

| Возможность | ChatGPT в браузере | Codex desktop / локальная агентная среда |
|---|---|---|
| Методология и выбор нужного навыка | После поддерживаемого подключения пакета; сохраняется весь каталог | После поддерживаемого подключения пакета; сохраняется весь каталог |
| Чтение документов | В пределах инструментов вложений и доступных форматов сессии | По разрешённому доступу к файлам и фактическим инструментам чтения |
| Официальный поиск | Требует доступного браузера/поиска; недоступные источники остаются пробелами | Требует сети и доступных браузерных/поисковых инструментов |
| Python runtime и автоматический сбор | Только если сессия реально предоставляет исполнение и доступ к файлам пакета | Через поставляемый адаптер при наличии Python и необходимых компонентов |
| OCR | Только при доступном OCR или исполняемой среде с нужными языками | После проверки Tesseract/языков и нужного преобразования страниц |
| Создание DOCX/PDF | Только через реально доступные средства создания/конвертации файлов | Через проверенный локальный стек; DOCX, PDF и просмотр страниц проверяются отдельно |
| Постоянная папка дела | Не предполагается; зависит от возможностей аккаунта/сессии | Отдельная пользовательская папка вне установленного пакета |
| Локальный MCP | Browser ZIP не объявляет локальный MCP и не соединяется с компьютером автоматически | Базовый runtime запускается локальными инструментами агента; MCP не считается настроенным по наличию ZIP |
| CasusLegal, HUDOC, дополнительные базы | Отдельная доступность сервиса и собственная авторизация | Отдельная доступность сервиса и собственная авторизация |
| Юридическое одобрение и подача | Действия человека; не создаются подключением пакета | Действия человека; технические проверки их не заменяют |

## Что проверяет первый запуск

Агент устанавливает фактический доступ к чтению файлов, браузеру, исполнению Python, записи результатов, обработке сканов и созданию документов. На локальном пути адаптер проверяет доступные операции и сохраняет собственный отчёт отдельно от существующей диагностики KSRF. Вывод относится к той среде и времени, где проверка выполнена.

Отсутствие PDF-конвертера ограничивает экспорт PDF, отсутствие OCR — чтение соответствующих сканов. Эти ограничения не означают невозможность анализировать уже доступный текст, искать источники или готовить помеченный рабочий проект. Неудачный запуск или доступ к сайту не является юридическим выводом по делу.

## Что означает проверка дистрибуции

Валидная структура плагина, разрешающиеся ссылки, проверенные хеши, успешный локальный запуск и синтетический документ подтверждают конкретные свойства программного пакета. Они не подтверждают установку в произвольном аккаунте ChatGPT, прохождение внешнего каталога, доступность каждого судебного сайта или юридическое качество будущего вывода.

При проверке на конкретном аккаунте отдельно зафиксируйте: способ импорта, принят ли полный пакет, какие навыки доступны, какие инструменты реально вызываются, где создаются файлы, сохраняется ли состояние после новой сессии. Пока этого нет, статус такой установки — **не проверено**. Публикация ZIP и размещение в публичном каталоге также различаются.

## Продолжить при ограниченной среде

Если пакет подключён, но исполнение отсутствует, помощник должен использовать доступные инструменты чата и отдавать полезный результат в их пределах. Например: опись вложений, замечания к тексту, список подтверждённых источников, рабочую редакцию и перечень недостающих документов. Он не должен придумывать выполненный CLI, созданный DOCX/PDF или проверенный выпуск.

Если нужна обработка папки, воспроизводимый OCR или полный локальный экспорт, используйте desktop ZIP в поддерживаемой локальной среде и поручите агенту подготовить её. Контейнерный вариант помогает воспроизвести системные зависимости; он сам не подключает локальные инструменты к браузерному ChatGPT. Для такого подключения требуются отдельно реализованные и проверенные транспорт, доступ и правила работы с данными.

Порядок начала работы — в [README.md](README.md), границы обработки документов — в [PRIVACY.md](PRIVACY.md).
