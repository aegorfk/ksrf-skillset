# Контракт реестра для локального обогащения

`scripts/enrich_ksrf_argument_patterns.py` и зеркальный `tools/enrich_ksrf_argument_patterns.py`
принимают `expanded_pattern_registry.json`, подготовленный локальным этапом
извлечения. До записи любых справочников файл должен быть JSON-объектом,
содержать все ожидаемые коды паттернов, а значение каждого ожидаемого кода —
массивом объектов. У каждой строки массива поле `number` обязательно и должно
быть непустой строкой.

Это только структурная граница входного артефакта: дополнительные поля и
содержательная полнота реестра проверяются отдельными этапами. Нарушение
границы даёт `ERROR:` и ненулевой код завершения без частично записанных
справочников; значения не преобразуются молча.
