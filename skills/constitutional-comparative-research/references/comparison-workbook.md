# Матрица сравнительного исследования

Используй подходящие поля, когда сравнение сложнее двух коротких выводов. Матрица служит объяснению, а не обязательной анкете пользователя.

## Вопрос и выборка

| Поле | Что установить |
|---|---|
| research_question | Один проверяемый вопрос, а не только тема |
| shared_function | Общая задача институтов или проверяемое различие функций |
| selection_reason | Почему эти суды/акты проверяют вопрос |
| population | Период, вид актов, язык, доступные источники |
| target_jurisdiction | Только если вывод нужен для применения в указанной стране |
| search_gaps | Какие пределы источников способны изменить результат |

Не отбирай только самые цитируемые или удобные решения. При ограниченном корпусе опиши выборку как выборку. Две системы не представляют автоматически «европейский подход».

## Карточка акта

| Измерение | Вопрос |
|---|---|
| Источник | Полный судебный текст, копия или только редакционный материал? |
| Производство | Абстрактный контроль, конкретный спор, индивидуальная жалоба, предварительный контроль? |
| Предмет | Что именно проверяется: закон, сложившийся смысл, действие или бездействие? |
| Право и субъект | Какое право и чей статус определяют защиту? |
| Вмешательство | Каким механизмом правило создаёт ограничение или недостаток гарантии? |
| Тест | Какие вопросы суд действительно ставит, как распределены бремя и интенсивность проверки? |
| Посылки | Какие юридические и фактические условия нужны для вывода? |
| Рассуждение | Какая операция связывает посылки с результатом? |
| Авторство | Суд/большинство, отдельное мнение, сторона, цитируемый источник? |
| Вывод | Какой узкий ответ необходим для результата? |
| Последствие | Недействительность, сохраняющее истолкование, отсрочка, указание законодателю, индивидуальная защита? |
| Время | Дата акта, применимая редакция, последующая практика и предел её проверки |

Для цитаты: `document_id + source_url + raw_sha256 + text_sha256 + quote_original + locator`. При локальном извлечении добавь `char_start/char_end`; локальный `p0001` не называй официальным пунктом. Перевод не подменяет оригинал и не используется для проверки совпадения хеша.

## Проверка сравнительного вывода

Запиши предполагаемое общее правило и попробуй его сузить:

- Если заменить статус судьи на работника частной организации, сохранится ли конституционное основание?
- Если заменить требование достаточного уровня оплаты на определённую формулу её пересмотра, останется ли вывод тем же?
- Если мера была временной, а затем многократно продлевалась, суд оценивал момент принятия или совокупный последующий эффект?
- Если мотивировка называет бюджетные последствия, они оправдывают нарушение, определяют предел проверки или только время действия remedy?
- Если выигравший заявитель получает пересмотр, даёт ли это тот же результат всем лицам и за прошлые периоды?

Не отвечай на эти вопросы по названиям институтов. Укажи фрагмент, решающий различие. Сохрани adverse case, более узкое прочтение и существенную неопределённость.

## Три независимые оценки

1. **Проверенность источника:** что фактически получено и сверено.
2. **Сравнимость:** в каком отношении акты можно сопоставлять.
3. **Юридический вес:** почему акт имеет значение в своей и, если нужно, целевой системе.

Хорошая официальная копия может оказаться несравнимой. Полезная гипотеза может происходить из ещё не сверенной копии. Сильная аналогия сама по себе не становится обязательным правом другой страны.
