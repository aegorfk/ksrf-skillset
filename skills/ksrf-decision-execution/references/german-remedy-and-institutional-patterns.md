# Немецкие remedial patterns как сравнительный critic

Используй этот справочник только для генерации вариантов и проверки переходных последствий. Немецкие формы решения не являются готовыми требованиями к КС РФ и не создают российское полномочие.

## Жёсткий competence gate

Каждый вариант проходит цепочку:

`точный нормативный дефект -> статус заявителя -> российское полномочие -> компетентный адресат -> допустимый правовой эффект -> мотивировочная/резолютивная часть -> отраслевой маршрут -> переходные и индивидуальные последствия`.

Нет официального российского якоря хотя бы для одного звена — вариант остаётся `comparative_only`.

## Сравнительные варианты

| Вариант | Что проверить, а не импортировать |
| --- | --- |
| `invalidity` | Допустимы ли прекращение действия и заявленный временной эффект |
| `incompatibility_without_immediate_nullity` | Может ли дефект быть признан без немедленного разрушения режима и кто обязан исправить его |
| `saving_construction` | Выдерживает ли текст сохраняющий смысл; не создаётся ли новая норма |
| `admonitory_warning` | Есть ли российская форма предупреждения и проверяемый адресат |
| `transition_period` | Кто устанавливает срок, как защищён заявитель и что происходит при бездействии |

Для каждого храни primary, narrower и fallback варианты, затронутых лиц, необратимый вред, риск правового вакуума и последствия отказа.

## Нормативная иерархия и пробел

Перед remedy построй цепочку:

`высшая норма -> компетенция -> применённая общая норма -> индивидуальный акт`.

Различай официальный источник права и убеждающий материал. Утверждение о пробеле может скрывать предложение создать новую норму; отдельно проверь, кто вправе сделать такой правотворческий шаг и не существует ли квалифицированное умолчание либо системное правило.

## Transfer pass

Иностранный пример допустим преимущественно как:

- отрицательный пример;
- карта возможных последствий;
- проверка более узкого средства;
- подтверждение варианта, уже имеющего внутренний российский якорь.

Совпадение названия remedial form или результата не доказывает совпадение полномочий и действия решения.
