# Конфиденциальность и изоляция дел

## Default

Любой пользовательский документ по умолчанию:

- `local_confidential`;
- доступен только текущему matter;
- не включён в cross-matter retrieval;
- не передаётся remote provider;
- не входит в skillset, fixtures или публичный отчёт.

## Перед внешней передачей

Покажи пользователю:

- provider;
- точные поля/фрагменты;
- цель;
- срок/retention, если известен;
- альтернативный local path.

Нужно operation-specific согласие. Наличие API key не является согласием на передачу case text.

## Минимизация

Передавай минимум, необходимый для bounded task. Для discovery используй обезличенный query profile, когда возможно. Не передавай полный пакет ради поиска одной нормы.

## Раздельные зоны

- public official evidence;
- case-local confidential evidence;
- private consent-controlled corpus;
- anonymized approved derivative;
- synthetic eval fixtures.

Индексы и embeddings наследуют privacy zone исходника. Отдельная projection не снижает класс конфиденциальности.

## Withdrawal и deletion

Отзыв согласия немедленно исключает запись и производные projections из retrieval и инвалидирует зависимые findings. Отзыв или expiry доверенного approval также немедленно блокирует promotion/shared use при следующей проверке. Удаление исходного файла выполняется только по отдельному явному указанию и с точным target manifest; audit tombstone сохраняет факт отзыва без private text.

## Жёсткий запрет на публикацию исходников жалоб

Исходники реальных жалоб не входят в публичный skillset ни при каких условиях. Запрет распространяется на оригинальные файлы, сканы, изображения страниц, OCR-выгрузки, извлечённый полный текст, приложения и иные производные, по которым жалобу можно восстановить. Публичная доступность материала, согласие пользователя или наличие ссылки на чужом сайте не снимают этот запрет.

В публичный репозиторий допустимо переносить только:

- методические карточки с выводами, которые не позволяют реконструировать исходную жалобу;
- синтетические и самодостаточные eval-сценарии без реального текста дела;
- SHA-256, служебный статус и минимальные сведения о происхождении без локального пути;
- активные внешние ссылки на публичный источник жалобы, профессиональный канал донора и итоговый акт КС РФ.

Для закрытой калибровки исходник хранится локально вне репозитория и связывается с карточкой только по hash или private ID. Ни пользовательский запрос, ни release-задача не могут превратить такой файл в публичную fixture.

Перед публикацией skillset машинный release-guard дополнительно проверяет отсутствие:

- файлов реальных жалоб, корреспонденции Секретариата и полнотекстовых производных;
- consent/person identifiers;
- connector tokens и tokenized URLs;
- local case paths;
- `.serena`, `__pycache__`, `*.pyc` и runtime output.
